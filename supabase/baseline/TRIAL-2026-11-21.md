## What this means for the move (step 3 onwards)

- **Change member ids while copying, not after.** 56 foreign keys point at `bulavata.profiles(id)`, all with
  `ON UPDATE NO ACTION`, and `profiles.id` references `auth.users(id)`. So rows are copied with the Sydney id
  replaced by the member's Ireland id in the same statement. For the one member this touches 1 profile, 1
  Talanoa post, 1 Sere item and 1 wallet row.
- **Storage paths carry the member id** as their first folder (the storage policies check
  `foldername(name)[1] = auth.uid()`). The Sere files (9 objects, about 3 MB) have to be copied to the new id's
  folder, and any stored `media_url` / path pointing at them updated.
- **Exposure moves as it is.** 11 security-definer functions are callable signed-out and 86 by any member, all
  through `/rest/v1/rpc/bv_*`. That is the app's design today; review it as part of the move, not after.
- **Separate finding about Ireland itself:** the branch could replay only 1 of Ireland's 429 saved migrations
  (`MIGRATIONS_FAILED` after `20260823212101`). The shared project cannot be rebuilt from its own migration
  history, which is the same gap Sota Kece had before step 1.
