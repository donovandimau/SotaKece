# Sere — make a photo sing (9 Nov 2026)

A member picks a photo and a sound, slides to the part they want (up to 60 seconds), and posts. The
finished video appears on the Talanoa Wall by itself, mates can tip the maker with a free gift, and
anyone can remix the sound with their own photo.

## Pieces
| Piece | Where | What it does |
|---|---|---|
| Rules | `supabase/migrations/20261109200000_sota_sere.sql` | tables `sere_scenes`, `sere_media_generations`; `talanoa_posts.sere_id`; `gifts.sere_id`; functions `bv_sere_create / mine / tip / play / remove`; the wall feed gains a `sere` object; buckets `sere-audio`, `sere-images` (private, per-member folders), `sere-video` (public); Realtime on the generations table; a trigger writes the wall post when a row turns `completed` |
| Maker | `sere-maker.js`, `sere-maker.css` | the sheet (photo, sound, trimmer, scene, caption), on-phone prep (photo to 1024px JPEG, sound cut to a 16 kHz mono WAV), uploads with progress, progress by Realtime, resume after the app was closed, tip sheet, play counting |
| Wall | `sota-pulse.js` | `🎤 Sere` button on the composer; video card (poster first, video only on tap), scene tint, 🎁 tip and 🎤 remix buttons |
| Server | `api/sere.js` | `start`: signs the two inputs for one hour, sends them to the lip-sync model with a signed webhook address; `check`: re-reads a job that looks stuck. `api/sere-callback.js`: the model's webhook — verifies the signature, re-reads the job with our token, copies the video and a poster into `sere-video`, marks the row completed |
| Tests | `tests/sere.test.cjs` (12), `tests/run-sere-db.cjs` + `tests/sere-db.sql` (41 SQL checks) | run with `node --test tests/sere.test.cjs` and `NODE_PATH="$PWD/tests/talanoa-tools/node_modules" node tests/run-sere-db.cjs` |

## Going live — Donovan's steps
1. Run `supabase/migrations/20261109200000_sota_sere.sql` in the SQL editor on dimau-core-sydney (it creates the three buckets too).
2. Vercel → sotakece → Settings → Environment Variables (Production):
   - `SOTA_SERVICE_KEY` — the project's service role key (Supabase → Project settings → API keys)
   - `REPLICATE_API_TOKEN` — from replicate.com → Account → API tokens
   - `SERE_SECRET` — any random text, 32+ characters
   - `SERE_REPLICATE_VERSION` — the version hash of the lip-sync model you pick on Replicate (open the model → "Versions"). SadTalker-style models take `source_image` + `driven_audio`, which is the default mapping. For a model with other input names set `SERE_INPUT_IMAGE`, `SERE_INPUT_AUDIO` and `SERE_INPUT_EXTRA` (JSON).
3. Redeploy (any push to main, or Redeploy in Vercel) so the functions see the variables.
4. Make one sere on sotakece.com and watch it land on the wall.

## Realistic notes
- Cost is per second of rendered video on Replicate, which is why the window is capped at 60 s and members get five a day. One 60 s render on a mid-range GPU is roughly one to four minutes.
- Scenes are applied as a light colour treatment on the card (the lip-sync model itself has no background or lighting settings). Swap to a model-side scene later by passing `sere_scenes.params` through `SERE_INPUT_EXTRA`.
- A render that never calls back is picked up when the maker opens the sheet again or taps "Check now" (there is no cron on this plan).
- Copyright: a member singing a commercial song and sharing it publicly is a takedown risk on the big platforms. The maker says "your own recording" in the picker copy; keep it that way.

## 9 Nov 2026, later — two engines, "Say my words", more doors in
- **Engines** (picked in the maker): *Quick* = SadTalker as before (about a minute, lips move); *Lifelike* = MEMO on Replicate (`zsxkib/memo`, 5–10 minutes, head/eyes/expression move, a few pence more). Column `engine` on the row; `bv_sere_create` takes `p_engine`. Override versions with `SERE_LIFELIKE_VERSION` / `SERE_REPLICATE_VERSION` if a model moves.
- **Say my words**: type up to 300 characters, pick a voice (Kokoro on Replicate, `jaaari/kokoro-82m`, English voices incl. UK), the server speaks it, writes the pending row as the member and uploads the sound; the rest is the same pipeline. `/api/sere` action `speak`. Override with `SERE_TTS_VERSION`.
- **More doors**: a "🎤 Make a photo sing" button on the Home, Music and My space heroes (sota-worlds.js), next to the Talanoa composer button.
- Migration `20261109220000_sota_sere_engines.sql` (adds the column, rebuilds the view, replaces `bv_sere_create`). Release v156.
- Known limits: one face per photo (both engines); voices are English only for now; Lifelike is capped at 60 s like Quick.
